# Smart Health & Fitness Tracker 🏋️‍♂️

A lightweight Python command-line interface (CLI) application designed to calculate Body Mass Index (BMI) and manage daily workout logs. Built using fundamental Python concepts, including custom functions, conditional logic, control loops, and list operations.

## Features

- **BMI Calculation:** Computes Body Mass Index from height and weight inputs and classifies the result into standard health categories (*Underweight*, *Healthy Weight*, *Overweight*, or *Obese*).
- **Workout Logging:** Appends new exercises to an in-memory session list in real time.
- **View Workouts:** Displays all currently logged exercises during the session.
- **Interactive CLI Menu:** Navigation loop that processes user options until manually exited.

## Tech Stack

- **Language:** Python 3.x
- **Dependencies:** None (uses standard built-in Python tools)
